## Introduction

[STWO](https://github.com/keep-starknet-strange/awesome-stwo) (Small THINs for Webassembly) is a Starknet-native STARK prover, designed to be efficient, verifiable, and accessible.

## Projects integrating STWO with Starknet

- [cairo-prove-kit](https://github.com/ILE-Labs/cairo-prove-kit) - A TypeScript SDK and Cairo application starter kit that gives Starknet developers a simple, abstracted interface for integrating S-two client-side proving into real applications without requiring knowledge of Rust, Circle STARKs, or the internals of the S-two crate. The SDK wraps the S-two Rust crate via WASM compilation and exposes a clean TypeScript API for local proof generation and verification, targeting web and Node.js environments. Built by [ILE Labs](https://github.com/ILE-Labs).
- [Snoozy](https://github.com/keep-starknet-strange/snoozy) - A simple Starknet prover for client-side proof generation.
- [Kakaroto](https://github.com/kkrt-labs/kakaroto) - A toolkit for integrating STWO with Starknet contracts.
